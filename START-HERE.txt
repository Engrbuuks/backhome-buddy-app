BACKHOME BUDDY — complete application, build 119
Exported from commit 9c601dd on main, 11 October 2026.

THIS IS THE WHOLE APP, NOT A PATCH.
Replace your local folder with this one. There is no bhb-skeleton subfolder in
here, and there should not be one in your project either: a second copy of the
app was the cause of the repeated build failures. The app builds from ./src.

WHAT YOU SHOULD SEE AFTER UNZIPPING
  src/  public/  supabase/  package.json  tsconfig.json  vercel.json
If you ever see a bhb-skeleton folder appear again, delete it.

SETUP
  1. npm install            (web-push is a new dependency)
  2. npm run typecheck      (should print nothing)
  3. npm run dev

DATABASE — run these in Supabase, in order. All are safe to re-run.
  supabase/migrations/0038_trust_tiers_and_identity.sql
  supabase/migrations/0039_task_offers.sql
  supabase/migrations/0040_push_and_offer_mode.sql

OPTIONAL — phone alerts for task offers
  npx web-push generate-vapid-keys
then set in Vercel:  VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY,
                     VAPID_SUBJECT=mailto:hello@backhomebuddy.ng
Leave them unset and push quietly does nothing; everything else works.

WHAT IS NEW IN 119
  Vetting      configurable checks, PCC no longer blocks, trust tiers,
               clearance tiers, optional vendor-agnostic identity checks,
               suspension actually enforced, completed-task counter
  Offers       paid tasks offered to a ranked buddy with a time window,
               atomic accept, declines with reasons, admin override intact
  Safety       offer mode defaults to ADVISORY — the system suggests and
               notifies, the admin still assigns. Switch to automatic only
               once alerts are proven to reach phones.
  Alerts       installable to a phone home screen, web push while closed,
               task offer notification can no longer be switched off,
               every send outcome recorded
